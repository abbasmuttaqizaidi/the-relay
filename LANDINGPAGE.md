## Brand & Style

This design system establishes a high-velocity, precision-oriented B2B marketplace environment where founders, corporate development heads, institutional investors, and strategic brokers exchange high-stakes deal flow. The visual tone balances decisive transaction capability with discreet, privacy-conscious institutional rigor. Every pixel conveys liquidity, speed, and discretion without devolving into visual noise.

The style unifies **Corporate Precision** with **Functional Minimalism**:
- **Discretion & Signal-to-Noise Ratio:** Dense, scannable data layouts eliminate vanity elements. Deal confidentiality is front-and-center through purposeful visual masking, verified escrow-style identifiers, and reciprocal reveal affordances.
- **Architectural Framing:** Structural definition relies on crisp 1px borders, subtle canvas layering, and high typographic discipline rather than dramatic dropshadows or skeuomorphism.
- **Controlled Kinetic Energy:** Strategic bursts of high-chroma orange direct executive gaze strictly to high-intent actions—deal claiming, bid introduction, reciprocal unmasking, and critical stage gates.

## Colors

The color architecture is built around calibrated contrast ratios, ensuring compliance with WCAG AAA standards on critical data surfaces.

### Core Roles
- **Primary Accent (`#F97316` - Relay Orange):** The definitive action and velocity color. Used exclusively for high-intent triggers (e.g., "Request Introduction", "Submit LOI"), deal momentum tickers, and critical progression markers. Never used purely for passive decorative surfaces.
- **Primary Foundation (`#171F2C` - Deep Charcoal):** The dominant structural color. Supplies authoritative contrast for titles, major data values, high-priority buttons, and active tabs.
- **Secondary Fill (`#F8FAFC` - Light Canvas):** Soft background tone utilized for outer canvas offsets, table header backgrounds, segmented controller wells, and recessed code blocks.
- **Structural Gray (`#E2E8F0` - Precision Border):** Used for grid lines, tabular dividers, card envelopes, and split-pane controls.
- **Secondary Body Text (`#64748B` - Slate Gray):** Dedicated to field labels, explanatory text, metadata keys, and secondary descriptors.
- **Muted Text (`#94A3B8` - Muted Gray):** Reserved for disabled states, ghost watermarks, empty-state cues, and non-interactive opportunity code framing.

### Functional Status Indicators
- **Verified Identity / Reciprocal Alignment (`#10B981` - Emerald):** Denotes verified institutional entities, mutual NDA signatures, confirmed liquidity, and active match parity.
- **Urgent / Hot Deal Surface (`#FFF7ED` fill with `#EA580C` text and `#FDBA74` border):** Distinguishes proprietary time-sensitive deal access or expiring exclusivity windows.
- **Confidential / Obfuscated Surface (`#0F172A` with `#38BDF8` accents):** Designates blinded deal parameters that require bilateral consent to reveal.

## Typography

The typographic hierarchy is split intentionally into three disciplined roles:
1. **Plus Jakarta Sans (Headings & Titles):** Balances geometric authority with modern micro-curves, delivering an executive, confident posture for valuation summaries and deal titles.
2. **Inter (Interface & Continuous Prose):** The workhorse UI font optimized for legible tabular data, dense data attributes, transaction terms, and high-frequency scan paths.
3. **JetBrains Mono (Identifiers, Metrics & Codes):** Strict monospaced treatment allocated to deal registry identifiers (e.g., `RY-0821`), financial metrics ($ ARR, EBITDA multiples), date timestamps, SHA verifications, and reciprocal match percentages.

Headlines larger than 32px automatically compress via mobile-specific tokens to prevent broken column alignments on field tablets and mobile views.

## Layout & Spacing

The design system operates on an 8-point base grid (subdivided to 4px for tight form controls and data density adjustments).

### Layout System
- **Desktop (1280px+):** A 12-column responsive fluid grid with `gutter: 1.5rem` and outer page `margin: 2rem`. Maximum container content width tops out at 1440px for single-window analytics, or dynamic full-width edge-to-edge for multi-pane deal pipeline boards.
- **Tablet (768px - 1279px):** 8-column layout. Left navigation collapses into an icon rail (64px width); secondary inspection panels stack under primary opportunity overviews.
- **Mobile (< 768px):** 4-column layout with `gutter-mobile: 0.75rem` and `margin-mobile: 1rem`. Multi-pane split layouts collapse into a stepped drill-down view (Feed -> Deal Preview -> Action Drawer).

### Spacing Application Rules
- `space-xs` (4px): In-badge gaps, icon-to-label inline offsets, compact status tags.
- `space-sm` (8px): Form input inner padding, micro-card metadata rows, table cell vertical padding.
- `space-md` (16px): Standard component internal padding, horizontal table cells, card body padding.
- `space-lg` (24px): Inter-card gaps, modal padding, primary dashboard section stacks.
- `space-xl` (40px): Canonical section splits, high-level screen segment breaks.

## Elevation & Depth

This system intentionally rejects ambient blur drop-shadows and heavy faux-3D layering. Depth is expressed through **structural perimeter layering and low-contrast borders**.

### Layering Philosophy
- **Base Canvas (Level 0):** Hex `#F8FAFC`. The foundational backdrop against which all modules sit.
- **Surface Elevation (Level 1):** Hex `#FFFFFF` strictly encased in a 1px solid `#E2E8F0` border. This is the standard card, deal row, and analytical widget surface.
- **Lifted / Interactive Surface (Level 2):** When a deal card or action module is hovered or focused, the background remains `#FFFFFF`, the border elevates to `#CBD5E1`, and a micro-offset structural shadow is applied: `0 1px 3px 0 rgba(23, 31, 44, 0.06), 0 1px 2px -1px rgba(23, 31, 44, 0.04)`.
- **Floating Overlays & Flyout Panels (Level 3):** Hex `#FFFFFF` with a 1px `#CBD5E1` border and a directed drop shadow: `0 10px 15px -3px rgba(23, 31, 44, 0.08), 0 4px 6px -4px rgba(23, 31, 44, 0.03)`. Used exclusively for LOI confirmation drawers, blinded parameter unlock modals, and global command palettes.
- **Privacy Masking & Reciprocal Blurs:** Blinded deal points use a semi-opaque `#F1F5F9` layer with a 6px backdrop blur, requiring a mutual introduction request to render legible.

## Shapes

The shape hierarchy is configured to **Soft (`1`)**, emphasizing institutional permanence and architectural order:
- **Default Elements (Inputs, Buttons, Cards, Dropdowns):** `0.25rem` (4px). Provides clean, crisp corners that maximize visual alignment along vertical data tracks.
- **Containers & Modal Shells (`rounded-lg`):** `0.5rem` (8px). Softens larger viewport-dominating containers without looking consumer-like.
- **Outer Shells & Overlays (`rounded-xl`):** `0.75rem` (12px). Reserved strictly for high-level transaction sheets and full-screen preview overlays.
- **Status Pills & Identity Chips:** Strictly full pill (`9999px`) to create an immediate shape-distinction between clickable rectangular controls and non-clickable informational status tags.

## Components

### Buttons & Action Drivers
- **Primary / High-Intent:** Solid Relay Orange (`#F97316`) background, `#FFFFFF` text, `0.25rem` border radius. Hover state transitions to `#EA580C`. Reserved strictly for affirmative deal steps ("Request Introduction", "Release Due Diligence").
- **Secondary / Authoritative:** Solid Charcoal (`#171F2C`) background with white text. Hover state `#334155`. Used for standard structural interactions (filtering, exports, profile switches).
- **Outline / Ghost:** Transparent background, 1px `#E2E8F0` border, `#171F2C` text. Hover brings a `#F8FAFC` background and `#CBD5E1` border.
- **Destructive:** Transparent background with `#DC2626` text and border; filled `#DC2626` only for terminal confirmations (e.g., "Retract Offer").

### Opportunity Badges & Verification Chips
- **Identity Verified:** Background `#ECFDF5`, text `#065F46`, border 1px solid `#A7F3D0`. Includes a 6px solid `#10B981` leading verification dot.
- **Proprietary / Featured:** Background `#FFF7ED`, text `#9A3412`, border 1px solid `#FED7AA`. Typographic label set in `label-caps`.
- **Deal Code Stamp:** Monospaced (`JetBrains Mono`), `#0F172A` text on `#F1F5F9` fill, bounded by a 1px `#E2E8F0` border. Format: `[RY-4820]`.

### Opportunity Feed Card
- Container: Background `#FFFFFF`, 1px solid border `#E2E8F0`, `space-md` internal padding, `rounded` (4px).
- Top Header Row: Split layout with Deal Code Stamp and Reciprocal Parity Score on the left; stage badge and relative listing age (`#94A3B8`) on the right.
- Body: Headline in `headline-sm`, followed by a 2-line obfuscated business summary. A 3-column data rail highlights: Revenue/EBITDA, Sector, and Location.
- Footer: Action bar containing bilateral disclosure state and a direct "Engage Opportunity" button.

### Form Inputs & Selectors
- Base Field: Height 40px, background `#FFFFFF`, border 1px solid `#E2E8F0`, text `#171F2C`, font `body-md`.
- Focus State: Border color sharply shifts to `#F97316` accompanied by a 1px ring `rgba(249, 115, 22, 0.2)`. Never standard browser blue.
- Labels: Formatted in `body-sm-medium` using `#64748B`.

### Checkboxes & Radio Controls
- Base: 16x16px boxes with `0.125rem` (2px) border radius for checkboxes, full circular for radios. Border 1px solid `#CBD5E1`.
- Checked State: Fill `#171F2C` (or `#F97316` when in deal-flow qualification matrices) with a crisp white centered check/dot.

### Reciprocal Deal Reveal Metric
- Specialized component indicating mutual unlock status. Rendered as a segmented horizontal ticker with dual-side participant icons, linked by an orange dynamic connection bar when terms match, or a dashed `#CBD5E1` line when blinded.
